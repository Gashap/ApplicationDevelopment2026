# ApplicationDevelopment2026

## Two Sum (LeetCode 1)

Задача: <https://leetcode.com/problems/two-sum/>, язык — C#.

### Часть 1. Два способа

Моё решение — [Solution.cs](ApplicationDevelopment2026/Solution.cs).

| Способ | Метод | Время | Память | LeetCode |
|---|---|---|---|---|
| a. «В лоб», два вложенных цикла | `TwoSum_A` | O(n²) | O(1) | Accepted, 65/65, 29 мс (лучше 43,59 %), 48,46 МБ (лучше 96,91 %) |
| b. HashMap, значение → индекс | `TwoSum_B` | O(n) | O(n) | Accepted, 65/65, 3 мс (лучше 97,76 %), 50,12 МБ (лучше 20,69 %) |

**Вывод-сравнение.** Перебор проверяет все пары, поэтому работает за O(n²) по времени и O(1) по памяти.
HashMap за один проход ищет дополнение `target − x` в словаре за O(1) в среднем, поэтому работает за O(n) по времени и O(n) по памяти.
На LeetCode это дало 29 мс против 3 мс, но память выросла с 48,46 до 50,12 МБ: скорость куплена памятью.
